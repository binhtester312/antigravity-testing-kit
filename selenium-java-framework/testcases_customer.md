# 📋 BỘ TEST CASE — MODULE CUSTOMERS (KHÁCH HÀNG)
**Hệ thống:** Perfex CRM — crm.anhtester.com  
**URL Module:** https://crm.anhtester.com/admin/clients  
**Phương pháp:** Risk-Based Testing (RBT) | Kỹ thuật: EP + BVA + Decision Table + State Transition  
**Dành cho dự án:** `selenium-java-framework`

## ⚖️ ĐÁNH GIÁ RỦI RO (Risk Assessment)

| Sub-Module | Risk Level | Lý do | Phạm vi TC |

| **Danh sách & Tìm kiếm / Lọc (Customer List & Search)** | 🔴 HIGH | Core Function — Quản lý, tra cứu & xuất dữ liệu | TC_011 → TC_016 (6 TCs) |

| **Quản lý Contact đại diện (Customer Contacts)** | 🟡 MEDIUM | Cổng truy cập Portal của khách hàng | TC_024 → TC_026 (3 TCs) |

## 📌 GIẢ ĐỊNH & NGUYÊN TẮC (Assumptions & Rules)

| ID | Giả định / Quy tắc |
|----|------------------|
| [A-01] | Trường **Company** là trường bắt buộc duy nhất trên tab Customer Details. |
| [A-02] | Thêm mới thành công khách hàng sẽ tự động redirect về trang chi tiết profile khách hàng vừa tạo. |
| [A-03] | Email của Contact đại diện phải là duy nhất (unique) không được trùng lặp trên toàn hệ thống. |
| [A-04] | Xóa khách hàng sẽ đồng thời xóa hoặc ngắt kết nối với các Contact thuộc về khách hàng đó. |
| [A-05] | Tìm kiếm (Live Search) trên bảng hỗ trợ tìm theo Tên Company, Primary Contact, Primary Email, Phone. |
| [A-06] | Mã khách hàng ID được hệ thống tự động sinh tăng dần (Auto-increment ID). |
